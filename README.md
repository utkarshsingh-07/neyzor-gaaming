# NEYZOR GAAMING

Premium React/Vite gaming & esports company website.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Customize

Company content lives in `src/data/company.js`.

Replace:
- `[TEAM MEMBER]`
- `00+` impact metrics
- partner placeholders
- social links
- contact destinations
- sample/upcoming events

No unsupported clients, revenue, awards, founding dates or achievements have been invented.
